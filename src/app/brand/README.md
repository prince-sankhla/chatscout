# Brand workspace

Phase 2 routes:
- `/brand/login` — brand sign-in entry
- `/brand/onboarding` — private brand profile setup
- `/brand` — brand dashboard
- `/brand/campaigns` — campaign management
- `/brand/campaigns/new` — campaign creation
- `/brand/campaigns/[id]/edit` — campaign editing
- `/brand/communities` — deterministic community matching
- `/brand/applications` — application review
- `/brand/selected` — selected community participation foundation
- `/brand/notifications` — brand activity notifications
- `/brand/settings` — profile settings

Campaign execution/proof/performance and real payments are intentionally outside Phase 2.
