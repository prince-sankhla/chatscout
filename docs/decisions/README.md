# Architectural Decision Records (ADR)

This directory contains important architectural and product decisions for ChatScout.

## Format

Each decision is documented as a separate markdown file with the format:

```
title: [DECISION TITLE]
date: YYYY-MM-DD
status: Accepted | Proposed | Superseded
---

### Context
Why was this decision needed?

### Decision
What was decided?

### Rationale
Why was this chosen over alternatives?

### Consequences
What are the implications?
```
